This project can help small scale enterprises, to automate their billing process. The administrator can login and add products in the system. This project contains many functionalities, such as menu(), administrator(), buyer(), add(), edit(), rem(), list(), receipt().
Theses functionalities can make your billing system much more efficient and helpful for the customer.

For testing purposes please download the main.cpp file, and run it in any latest C++ compilers, like gcc or mingiw.
